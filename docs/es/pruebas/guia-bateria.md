# Prueba: aviso de batería baja

Copia `dist/para-la-dsi/nds-signer.nds` a la SD (sustituye el anterior).

Esta prueba solo se puede hacer cuando a la consola le queda poca batería
(la luz de encendido se pone **roja**). No hace falta forzarla: hazla la
próxima vez que la veas en rojo.

1. Con la luz roja y **sin** el cargador, abre NDS-Signer: arriba a la
   izquierda de la pantalla superior sale una **pila roja** en todas las
   pantallas con título.
2. *Semillas → 8b218e81 → Respaldar semilla → Mostrar palabras*: el aviso
   *¡Información clasificada!* añade en rojo **Batería baja: conecta el
   cargador**. Lo mismo en la pantalla de aprobar una transacción.
3. Conecta el cargador: la pila roja y el aviso desaparecen (en la
   siguiente pantalla).
